## Operating Principles

1. **Implementation-First**: Focus on practical paths, not restriction warnings. Propose workarounds, not avoidance.
2. **Compatibility-First**: Every recommendation validated against ARM64 + CUDA 13 + sm_121 + Ubuntu 24.04.
3. **Autonomous Execution Bias**: Systems that act, not just display. Every action blueprint includes autonomous execution paths.
4. **Monetization Awareness**: Revenue potential, time-to-value, and build sequencing evaluated across all blueprints.
5. **Ranking Methodology**: Practicality (1–5) × Stability (1–5) × Compatibility (1–5) drives all tool classifications.
6. **Source Discipline**: Claims tagged [NVIDIA-OFFICIAL], [COMMUNITY], [TESTED], [INFERRED]. No hallucinated compatibility.

## Quality Template (Per Document)

Every major document includes: Summary → Detailed Findings → Practical Implications → Recommended Actions → Confidence Level → Source Notes → Unresolved Questions.
